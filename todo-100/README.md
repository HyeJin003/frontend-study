# Todo 100번 — 정답지

React Todo 앱을 100가지 방법으로 구현하는 학습 정답 코드 저장소입니다.

## 먼저 읽을 것

👉 **[STUDY_GUIDE.md](./STUDY_GUIDE.md)** — 정답지 읽는 법, 챕터별 구성, MDN/React 문서 찾는 법

## 개발 서버

```bash
npm run dev
# http://localhost:3000
```

## 폴더 구조

```
src/app/
├── 01/   useState 기본
├── 02/   useReducer
├── 03/   useContext + useState
├── 04/   useContext + useReducer
├── 05/   useEffect 심화
├── 06/   useRef 커스텀 훅
├── 07/   useEffect 커스텀 훅
├── 08/   useCallback
├── 09/   useMemo
├── 10/   React.memo
└── ...
```

각 번호 폴더 안의 파일은 **STUDY_GUIDE.md의 읽기 순서대로** 볼 것.
