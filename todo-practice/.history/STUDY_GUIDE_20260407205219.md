       # 📚 Todo 100번 학습 가이드

## 학습 순서

### 1단계 — 정답 코드 읽기 (todo-100/)

- `todo-100/src/app/01/page.tsx` 열기
- 전체 코드를 천천히 읽는다
- 주석의 "왜?"를 이해한다
- 모르는 부분은 주석을 다시 읽는다

### 2단계 — 손으로 타이핑 (todo-practice/)

- `todo-practice/src/app/01/page.tsx` 열기 (비어있는 틀)
- 정답 코드를 보면서 **손으로 직접 타이핑**
- 복사 붙여넣기 절대 금지
- 타이핑하다 막히면 → 정답 확인 → 이해 → 계속

### 3단계 — 브라우저 확인

```bash
cd todo-practice
npm run dev
```

- 기능이 정답과 똑같이 동작하는지 확인
- 에러 나면 → 에러 메시지 읽기 → 스스로 해결 시도
- 해결 못하면 → `todo-100` 정답 코드와 비교

### 4단계 — 덮고 다시 짜기 (실력 확인용)

- 정답 코드 닫기
- 아무것도 없는 상태에서 처음부터 다시 짜기
- 막히면 "아, 이 부분을 아직 모르는구나" 확인 후 정답 참고

## 다음 버전으로 넘어가는 기준

```
✅ 이 코드가 왜 이렇게 동작하는지 설명할 수 있다
✅ 비슷한 상황에서 이 패턴을 떠올릴 수 있다
→ 다음 번호로 이동
```

## 핵심 마인드셋

```
❌ "일단 돌아가면 됐지" → 취직 안 됨
✅ "왜 이렇게 짰는지 면접에서 설명할 수 있다" → 합격
```
